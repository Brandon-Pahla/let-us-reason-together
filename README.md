# Let Us Reason Together

A personal Bible-study blog. Static Astro site, no client-side JavaScript.

Requires Node 24 (see `.nvmrc`).

```sh
npm install
npm run dev      # local dev server
npm run build    # static output in dist/
npm run preview  # serve dist/
```

Posts live in `src/content/posts/` as Markdown files whose body is raw HTML (the studies use tables and nested blockquotes that must be kept exactly).
